## How to resume play

### Prerequisites

1. Start the gym server:

```bash
python autoplay/gym_ctl.py start --story autoplay/curses.z5 --port 7777 --max-turns 2200 --seed 1
```

2. Verify it is running:

```bash
python autoplay/gym_ctl.py status
```

### Restore a checkpoint

The game has been won, so any new connection starts a fresh game. To
resume from a specific point, restore a checkpoint:

```bash
python autoplay/gym_client.py --port 7777 --command "__load wp46"
```

`__load` works even after the game has ended: it starts a fresh game and
overwrites the state with the snapshot. The turn budget resets to 0 on
load.

### Sending commands

One command at a time:

```bash
python autoplay/gym_client.py --port 7777 --command "look"
```

Batch mode (multiple commands on one connection):

```bash
python autoplay/batch_play.py "look;;inventory;;north"
```

Commands are separated by `;;`. The batch script (`autoplay/batch_play.py`)
was written this session and is not committed to the repo.

### Saving a new checkpoint

```bash
python autoplay/gym_client.py --port 7777 --command "__save myname"
```

Saves to `autoplay/.gym_save_myname.dat` (gitignored).

### Stopping the server

```bash
python autoplay/gym_ctl.py stop
```

### Chasing 550/550

The missing point is the 5 BONUS points (awarded for kissing Jemima,
giving her the chocolate biscuit, etc.) that are removed four turns
after being earned. To keep them, you must earn them for the first time
at the very end and immediately race to the Attic to go `down` before
the author takes them back. This requires careful turn-counting from
the bonus-earning action to the win. The prior 549/550 walkthrough
report (`Progress_Report_Curses.md`) notes this is "utterly mad" and
the honest ceiling for a normal playthrough is 549.
